Características Principales

Conexión SSH Segura

Conéctate a múltiples servidores mediante SSH con autenticación por contraseña o clave privada.

Gestión de Docker

Administra contenedores Docker: inicia, detén, reinicia, visualiza logs en tiempo real y monitorea recursos.

Monitoreo en Tiempo Real

Visualiza CPU, memoria, disco, red y procesos del sistema con gráficos actualizados automáticamente.

Sistema de Alertas

Configura alertas personalizadas para CPU, memoria, disco y contenedores Docker con detección de tendencias.

Terminal SSH Integrada

Ejecuta comandos directamente en tus servidores con una terminal SSH integrada y desplegable.

Gestión de Procesos

Filtra y administra procesos del sistema, visualiza detalles y finaliza procesos directamente desde la interfaz.
